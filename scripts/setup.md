# Setup del entorno – Vigilant-Pro

## Instalación

1. Instalar Python 3.10.9.

2. Instalar dependencias:

pip install -r requirements.txt

3. Verificar la existencia de:

- models/yolo26n.pt
- models/best.pt

4. Verificar que FFmpeg esté presente en:

ffmpeg-8.1-essentials_build/

5. Ejecutar el sistema:

python Mecs_sentinel.py
